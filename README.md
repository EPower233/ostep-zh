# 操作系统导论 · Operating Systems: Three Easy Pieces

《操作系统导论（OSTEP）》中英双语在线阅读版，支持中英分屏对照、全文检索、深浅色主题与原生矢量插图。

- **在线阅读**：<https://epower233.github.io/ostep-zh/>

## 阅读特性

- **中英对照阅读**：宽屏（≥ 1280px）下可在章节页开启「中英对照」双栏分屏与同步滚动（中文在左，英文在右），亦可单独切换中文版或英文 1.10 版。
- **清晰章节与检索**：左侧按全书各篇分章导航，右侧实时展示小节大纲，支持站内全文检索。
- **代码、公式与表格**：支持代码高亮、折叠与一键复制，完整渲染 LaTeX 数学公式、标准脚注与参考文献跳转。
- **明暗自适应矢量插图**：全书插图均为原生矢量 SVG，自动适配浅色与深色模式。
